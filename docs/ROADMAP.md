# 后续功能

当前可以使用的功能和安装步骤见[本地助手说明](../apps/local/README.md)。下面列出尚未提供、计划逐步完善的功能；没有写入实测记录的机型仍需自行验证。

## 更容易完成首次配置

- 在一个页面完成环境检查、小米登录、设备选择、模型设置和播报测试。
- 遇到账号验证时保留已填内容，验证完成后继续配置。
- 自动列出账号下的音箱，按型号测试播报、暂停和唤醒能力。
- 从所选模型服务读取可用模型，并检查连接与参数是否兼容。
- 显示“模型已回复”“音箱已接受播放”，再确认是否真正听到声音。

## 更清楚地排查问题

- 账号过期、模型限流、余额不足和网络中断分别给出恢复步骤。
- 查看后台服务状态，避免同一台音箱启动多个实例。
- 日志自动轮转，支持导出隐藏凭证的诊断信息。
- 完善音乐、音量、闹钟和家电口令的识别。
- 改善连续对话中的退出、打断和背景声处理。

## 更多安装方式和设备验证

- 简化 macOS 安装、升级和卸载。
- 补充经过验证的 Docker、NAS、Windows 和 Linux 使用说明。
- 按型号与固件整理兼容表，区分实测结果和社区反馈。

欢迎反馈实际使用结果。报告问题时请附上音箱型号、固件版本、运行系统、复现步骤和脱敏后的错误信息，不要上传 `.env`、`.mi.json`、账号密码或完整 Cookie。
