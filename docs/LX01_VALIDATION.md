# 小爱音箱 mini（LX01）验证记录

日期：2026-09-09。环境：macOS 26.6、Node 24、MiGPT-Next 1.3.2、AI Plug 提供的 gpt-5.6-luna。此记录来自单台用户自有设备，未记录账号、设备编号、MAC、密钥或登录缓存。

| 能力 | 结果 | 范围 |
|---|---|---|
| 小米 passToken 登录 | 通过 | 密码登录触发额外验证，浏览器登录凭证可用 |
| 自动列出设备 | 通过 | 硬件 LX01 |
| 云端对话记录 | 可读取 | 依赖小米云接口 |
| MiNA TTS | 用户确认能出声 | 默认播报路径 |
| 原生回答暂停 | API 接受；用户复测只有一次完整回答 | 仍可能先说出少量字词 |
| 播报状态 | MiNA playing → idle；MIoT 4,1：1 → 0 | 一次约 16 秒的采样验证 |
| 远程唤醒 | MIoT 5,2 接受 | 在确认播报结束后调用 |
| 无前缀问题 | 后台收到并成功回答 | 不要求“请问” |
| 连续问答 | 口令 → 播报 → 唤醒 → 提问 → 模型回答 → 再次唤醒 | 软件实现，非原生连续对话保证 |
| 单次问答延迟 | 若干次约 4.4–7.1 秒 | 从程序收到问题到提交播报；不是 P95，不含全部语音识别延迟 |

设备对原生“打开连续对话”曾回复“好像超出我的能力范围了”。本地适配层复用口令，通过播报状态检测和再次唤醒实现后续聆听。

未验证：其他机型/固件、Windows、Linux、Docker、全天候稳定性、网络断开恢复、长期 token 刷新、多人或电视背景声环境。不得把单机成功改写为“全机型支持”“完全无延迟”或“完全离线”。
