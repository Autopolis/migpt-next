# 社区维护路线图

目标：让拥有闲置小爱音箱的用户，在清楚兼容范围和费用的前提下，完成第一次大模型语音问答。

## 当前版本

`apps/local` 是实机验证后的开发者预览：支持 mini LX01 的基本问答、无前缀提问、语音开关连续对话、播报完成后唤醒、本地凭证表单和 macOS 后台管理。仍依赖小米云端接口；仅有单台 LX01 验证记录。

## 下一阶段：首次使用向导

1. 检查运行环境与网络，显示代理和接口问题的具体原因。
2. 连接小米账号；遇到额外验证时暂停并保留进度。
3. 自动列出设备，按实际能力测试选择播报与唤醒方案。
4. 选择模型服务：可选 AI Plug 或自定义兼容服务；明确维护方关联，显示费用来源，不静默更换模型。
5. 完成模型回答和音箱出声测试，再开启后台服务。

成功标准是用户听到真实回答，而不是配置保存成功或 API 返回 200。

## 稳定性与兼容性

- 配置迁移、启动单实例检测、自动日志轮转、脱敏诊断导出。
- 网络断开恢复、token 到期提示、模型限流与余额不足状态。
- 原生控制口令覆盖与误分类回归测试。
- 连续对话：取消、退出、播报中插话、环境噪声、五分钟上下文过期。
- 机型矩阵标注“实测”“社区报告”“待验证”，逐项记录固件和能力，不宣布全机型支持。
- 由用户自行选择是否提交兼容性反馈；默认不上传对话和凭证。

## 分发

- 优先提供 macOS 本地启动体验；签名安装包在冷启动和安全验证通过后发布。
- 第二阶段提供经过验证的 Docker/Compose 与 NAS 指南。
- Windows、Linux 和新机型均需单独完成测试，不能把 Node 可运行当作平台支持证明。

## 暂不承诺

刷机、离线识别、全双工即时打断、所有小爱型号、任意模型自动兼容、无人维护的永久运行。完整的图形向导、安装包和自动模型发现尚未实现。
